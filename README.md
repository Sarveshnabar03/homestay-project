# Homestay Project

A full-stack Homestay Booking & Service Marketplace platform built using Node.js, Express, MySQL, and JavaScript.

## Features

* User Authentication
* Provider Dashboard
* Admin Dashboard
* Booking System
* Chat System
* QR Payment Upload
* Payment Verification
* Role-based Access
* Responsive UI

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: MySQL
* Authentication: JWT / Session

## Future Improvements

* Online Payment Gateway
* Notifications
* Maps Integration
* Reviews & Ratings
* Deployment
